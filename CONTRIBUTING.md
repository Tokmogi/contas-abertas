# Como contribuir

Obrigado pelo interesse! O Contas Abertas é feito para ajudar organizações sociais, e toda contribuição
conta: código, design, textos, testes com ONGs reais ou ideias.

## Primeiros passos

1. Procure uma [issue](https://github.com/Tokmogi/contas-abertas/issues) (as marcadas com
   `good first issue` são ótimas para começar) ou abra uma nova com sua sugestão.
2. Faça um fork, crie uma branch (`git checkout -b minha-melhoria`) e siga o "Como rodar" do README.
3. Rode os testes com `pytest` antes de enviar.
4. Abra um pull request explicando o que mudou e por quê.

## Princípios

- **Simples primeiro:** quem usa é voluntário, não contador. Evite termos técnicos nas telas.
- **Celular primeiro:** teste suas telas numa largura pequena.
- **Privacidade:** nunca publique dados pessoais ou comprovantes na página pública.
